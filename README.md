# Как запустить этот сайт (пошагово, для новичка)

## Что у вас должно получиться в итоге
Сайт с меню, корзиной и оплатой через ЮKassa, работающий на вашем домене,
с юридическими документами и настроенной выдачей чеков.

---

## Шаг 1. Домен
1. Зарегистрируйте домен (например, на reg.ru или nic.ru) на ваше ИП.
   Стоимость домена в зоне .ru — обычно 200–300 ₽/год.

## Шаг 2. Хостинг
Обычный хостинг для сайтов-визиток (только HTML) НЕ подойдёт — нужен
хостинг, который умеет запускать код на Node.js.

Рекомендация: **Timeweb Cloud** (timeweb.cloud) — раздел "Приложения" /
"Apps", поддерживает Node.js, сервера физически в России (это важно —
персональные данные российских покупателей по закону должны храниться
на серверах в РФ). Подойдут и другие хостинги с поддержкой Node.js
и серверами в РФ (Selectel, Beget Cloud и т.п.).

## Шаг 3. Загрузка кода
1. Скачайте все файлы, которые я подготовил (папку `site`).
2. В панели хостинга создайте новое Node.js-приложение и загрузите туда
   содержимое папки `site` (обычно можно загрузить zip-архив или
   подключить через Git — в панели Timeweb это делается через кнопку
   "Загрузить файлы" или подключение репозитория).
3. В настройках приложения укажите команду запуска: `npm install && npm start`
   (или выполните `npm install`, а потом `npm start`, если хостинг просит
   команды отдельно).

## Шаг 4. Настройка ЮKassa
1. Зайдите в личный кабинет ЮKassa → **Настройки → API-ключи**.
2. Скопируйте `shopId` и **тестовый** секретный ключ (для первой проверки).
3. В панели хостинга найдите раздел "Переменные окружения" (Environment
   Variables) и добавьте туда значения из файла `.env.example`:
   - `YOOKASSA_SHOP_ID`
   - `YOOKASSA_SECRET_KEY`
   - `SITE_URL` — адрес вашего сайта, например `https://vasha-dostavka.ru`
   - `PORT` — обычно хостинг подставляет его сам, можно не трогать

   Если хостинг не поддерживает переменные окружения через панель,
   переименуйте `.env.example` в `.env` прямо в загруженной папке и впишите
   значения туда руками.

4. **Обязательно включите услугу "Онлайн-касса" (фискализация чеков)**
   в кабинете ЮKassa. По закону 54-ФЗ каждая онлайн-оплата должна
   сопровождаться кассовым чеком — без этой услуги приём оплаты будет
   нарушением закона и может привести к штрафу.

## Шаг 5. Вебхук (уведомления об оплате)
1. В кабинете ЮKassa: **Настройки → HTTP-уведомления**.
2. Укажите адрес: `https://ваш-домен.ru/api/yookassa-webhook`
3. Включите события `payment.succeeded` и `payment.canceled`.

Это нужно, чтобы сайт узнавал, что оплата реально прошла (без этого
шага заказы будут создаваться, но не будут помечаться оплаченными).

## Шаг 6. Подключение домена
В панели регистратора домена (там, где покупали домен) укажите A-запись,
которая указывает на IP вашего хостинга — точную инструкцию даст
поддержка хостинга, обычно это готовая кнопка "Привязать домен".
SSL-сертификат (https) на большинстве хостингов выпускается автоматически.

## Шаг 7. Заполните свои данные в коде
Перед запуском замените плейсхолдеры на свои реальные данные в файлах:
- `public/index.html` — название бренда, реквизиты ИП в подвале сайта
- `legal/privacy-policy.html` — данные ИП, email, адрес
- `legal/offer.html` — данные ИП, email, адрес
- `products.json` — ваше реальное меню и цены (этот файл можно менять
  и после запуска, без какого-либо программирования — просто открыть
  текстовым редактором и поправить цифры/названия)

## Шаг 8. Тест
1. Сделайте тестовый заказ на сайте, используя тестовую карту ЮKassa
   (номера тестовых карт есть в документации ЮKassa в разделе "Тестирование").
2. Проверьте, что заказ появился в файле `orders.json` на сервере со
   статусом "оплачен".
3. Когда всё работает — замените тестовый секретный ключ ЮKassa на боевой
   (в личном кабинете нужно будет пройти проверку данных ИП для боевого режима).

---

## Важно про законы РФ (кратко, не является юридической консультацией)
- **152-ФЗ / 242-ФЗ**: персональные данные покупателей должны храниться на
  серверах в РФ → поэтому выбран российский хостинг.
- **54-ФЗ**: при онлайн-оплате обязателен кассовый чек → включите
  "Онлайн-кассу" в ЮKassa (шаг 4).
- **Закон "О защите прав потребителей"** и правила дистанционной торговли:
  на сайте должны быть реквизиты продавца, договор оферты, условия
  возврата — шаблоны есть в папке `legal`, но их обязательно нужно
  адаптировать под ваш бизнес и лучше показать юристу или бухгалтеру
  перед стартом продаж.
- **436-ФЗ**: рекомендуется возрастная маркировка сайта (значок "0+" уже
  добавлен в шапку сайта).

## Что можно улучшить в будущем
- Сейчас заказы хранятся в простом файле `orders.json` — для небольшого
  количества заказов этого достаточно, но при росте лучше перейти на
  настоящую базу данных.
- Сейчас нет админ-панели — заказы можно посмотреть, открыв файл
  `orders.json` на сервере. Позже можно добавить простую страницу
  со списком заказов.
- Рекомендуется проверять, что вебхук действительно приходит от ЮKassa
  (сверка по IP-адресам ЮKassa), чтобы никто не мог подделать
  уведомление об оплате.
